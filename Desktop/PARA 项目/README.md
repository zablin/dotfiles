# 🧠 PARA 知识管理系统

欢迎使用基于 LifeOS 理念的 PARA 知识管理系统！

## 🎯 什么是 PARA 方法？

PARA 是由 Tiago Forte 提出的知识管理方法，将所有信息分为五个类别：

- **📋 [项目](./项目/)** - 有明确截止日期和具体成果的工作
- **🏠 [领域](./领域/)** - 需要持续维护的责任区域
- **📚 [资源](./资源/)** - 未来可能有用的参考材料
- **📦 [归档](./归档/)** - 已完成或不再活跃的内容
- **📅 [日记](./日记/)** - 日常记录和思考反思

## 🚀 快速开始

### 1. 启用插件
- 设置 → 社区插件 → 关闭安全模式
- 启用 "LifeOS PARA Core" 插件

### 2. 开始使用
- `🎯 创建新项目` - 管理有时限的工作
- `🏠 创建新领域` - 维护持续性责任
- `📚 创建新资源` - 收集参考材料
- `📅 创建今日笔记` - 每日回顾计划
- `📅 日历视图` - 可视化查看日记并快速创建

## 📋 插件命令

| 命令 | 功能 |
|------|------|
| 📋 创建新项目 | 创建项目管理文件 |
| 🏠 创建新领域 | 创建领域维护文件 |
| 📚 创建新资源 | 创建资源收集文件 |
| 📅 创建今日日记 | 生成今日日记 |
| 📅 日历视图 | 查看日记日历并快速访问 |
| 🔍 搜索日记 | 检索历史日记内容 |
| 📊 日记统计 | 查看写作统计数据 |
| 🔄 重新初始化 | 重建PARA结构 |

按 `Cmd+P` 打开命令面板，搜索这些命令即可使用。

## 💡 使用建议

### 📋 项目管理
- 每个项目都要有明确的完成标准
- 定期回顾项目进展
- 完成后及时归档

### 🏠 领域维护
- 为每个领域设定维护标准
- 定期检视各领域状态
- 将相关项目与领域关联

### 📚 资源收集
- 即时收集有价值的信息
- 定期整理和分类
- 删除过时的资源

### 📅 日记管理
- 每日记录重要事件和思考
- 使用搜索功能快速查找历史记录
- 定期查看统计数据了解写作习惯
